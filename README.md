## Quick start

Create and activate virtual environment
python3 -m venv .venv  
source .venv/bin/activate

Install dependencies inside the venv  
pip install --upgrade pip  
pip install -r requirements.txt

Run TFTOOL from the repository root  
python3 tftool.py
